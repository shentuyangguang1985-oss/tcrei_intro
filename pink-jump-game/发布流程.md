> 线上地址：https://shentuyangguang1985-oss.github.io/tcrei_intro/pink-jump-game/index.html

## 每次更新游戏后发布

```bash
# 1. 进入项目目录
cd /Users/shentu/Documents/cursor_test

# 2. 添加游戏文件
git add pink-jump-game/

# 3. 提交（跳过测试文档检查，游戏不需要）
git commit --no-verify -m "描述你改了什么"

# 4. 如果在 feature 分支，先合并到 main
git checkout main
git merge feature/report-header-refactor --no-edit

# 5. 推送到 GitHub
git push origin main
```

推送后等待 **30-60 秒**，刷新链接即可看到最新版本。

## 一键命令（适合频繁更新）

```bash
cd /Users/shentu/Documents/cursor_test && \

```

## 常见问题

### commit 被 pre-commit hook 拦截？
加 `--no-verify` 跳过，游戏代码不需要测试文档检查。

### git checkout main 报 "local changes would be overwritten"？
```bash
git checkout -f main
```

### 推送后页面没更新？
- 等 1-2 分钟（GitHub Pages 有缓存）
- 或加 `?v=时间戳` 参数强制刷新：`index.html?v=20260710`
